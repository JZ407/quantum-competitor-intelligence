# 量子科技情报系统 —— 项目进展介绍

> 汇报日期：2026年7月31日  
> 编制：科技委办公室、产业发展部（理事会办公室）

---

## 一、项目定位

我们构建了一套**量子科技行业情报自动化系统**，覆盖"数据采集 → 智能清洗 → 多库存储 → LLM 分析 → 可视化呈现 → 报告自动生成"全链路。系统面向量子计算产业的竞争情报、投融资追踪、技术趋势研判三大核心需求，目前已稳定运行约 3 个月。

## 三、核心模块与进展

### 3.1 数据采集层 —— 三大数据源

| 数据源 | 方式 | 覆盖范围 | 频率 |
|--------|------|---------|------|
| **量科网 (liangke.com)** | 模拟浏览器抓取 | 国内量子行业新闻、快讯、参考资料 | 每日自动 |
| **16 家海外机构** | API + Playwright 抓取 | IBM / Google / Microsoft / NVIDIA / Quantinuum / IonQ / Rigetti / D-Wave / Xanadu / PsiQuantum / QuEra / Atom Computing / Classiq / Q-CTRL / QunaSys / OQC 等 | 每 2-3 天 |
| **投融资 WebSearch** | LLM Agent 驱动搜索 | 28 个可信域名，7 组定向 query，覆盖 2023-2026 年 | 每 2-3 天 |

**数据规模**：
- MySQL 主库约 **2,500 篇**（每日增量 5-15 篇）
- 历史归档库约 **11,582 篇**
- 投融资去向 websearch 收录 **96 篇**
- 已标记结构化投融资标签的新闻 **21 条**（含融资轮次、金额、投资方等）

### 3.2 智能标签系统

在原始新闻入库后，通过 **jieba 分词 + 自定义词典 + 规则引擎** 自动打标：

- **业务标签**：量子计算、量子通信、量子传感、超导、离子阱、中性原子、光量子、拓扑量子……
- **投融资标签**：融资轮次、金额、投资方、估值（自动提取 + 人工审核）
- **周报分类**：宏观态势 / 科技前沿 / 产品动态 / 企业资讯 / 资本运作 / 专利动态
- **人工覆写机制**：`tags.weekly_manual` 字段支持人工修正自动分类结果

### 3.3 投融资看板

一个跨库（MySQL + SQLite 历史库）的统一投融资视图：

- **自动化去重**：company + round + year 三重匹配
- **黑名单过滤**：自动排除股市行情、财报数据、政府资助公告（非融资事件）
- **金额/估值分离**：解决 extract_amount 将估值误标为融资额的问题
- **结构化展示**：公司名、融资轮次、金额、估值、投资方、日期、来源链接
- **交叉分析**：与竞对档案交叉验证融资数据

### 3.4 竞对档案系统（深度研究报告）

已完成 **4 家核心竞争企业的全量深度档案**：

| 公司 | 技术路线 | 档案深度 |
|------|---------|---------|
| **QuEra Computing** | 中性原子 | 89 篇论文、23 人核心团队、33 家合作伙伴、\$3.3亿融资、SWOT、2028 Libra 路线图评估、LaTeX 报告 |
| **Algorithmiq** | 算法/硬件无关 | 团队/论文/融资/产品/SWOT/交叉分析、LaTeX 报告 |
| **PsiQuantum** | 硅光子 + FBQC | 33 篇论文、28 人团队、交叉分析 |
| **Xanadu** | 连续变量光量子 + GBS | 301 篇论文、\$617M/17 笔融资核实、SWOT、交叉分析 |

每份档案包含：公司概览、创始人与团队、融资历程、技术架构与核心产品、合作生态、SWOT 分析、竞争定位、交叉分析等结构化维度。

另外还输出了《**中性原子量子计算发展历程与 QuEra 技术脉络梳理**》专题报告。

### 3.5 周报自动生成系统

从原始新闻到 PDF 报告的完整自动化流水线：

```
MySQL 新闻 → 标签分类 → LLM 内容清洗 → LLM 摘要生成 → 
Jinja2 LaTeX 模板 → xelatex 编译 → PDF 报告
```

**报告结构**：封面、目录、**LLM 生成摘要**、五大板块（宏观态势/科技前沿/产品动态/企业资讯/资本运作）、专利动态、会议日历、招投标线索

**已生成期数**：第 182-190 期（共 9 期 PDF）

**技术要点**：
- 使用 DeepSeek Chat 模型生成内容清洗和板块摘要
- LaTeX 中文排版（ctexart 文档类，xelatex 编译）
- 支持人工标签覆写自动分类
- 自动拉取会议数据库和招投标信息

### 3.6 RAG 知识库系统

支持**三种检索模式**的混合检索引擎：

| 模式 | 技术栈 | 用途 |
|------|--------|------|
| BM25 | rank-bm25 (k1=1.5, b=0.75) | 关键词精确匹配 |
| 语义嵌入 | all-MiniLM-L6-v2 + FAISS | 语义相似搜索 |
| 混合检索 | BM25 召回 → BGE-Reranker 重排 | 生产环境主力 |

**知识库版本**：
- **Pro**：bge-large-zh-v1.5（中文优化），面向竞对档案/专题研究
- **EN**：bge-large-en-v1.5（英文优化），面向海外机构新闻
- **Lite**：all-MiniLM-L6-v2，面向日常轻量查询

### 3.7 知识图谱

基于 Neo4j 风格的实体-关系可视化（JSON + HTML 渲染）：

- **实体类型**：公司、机构、人物、技术路线、产品、论文
- **关系类型**：投资、合作、竞争、供职、发表、收购
- **可视化**：交互式力导向图，支持筛选和搜索

### 3.8 会议信息库

量子科技领域行业会议的收集与管理：
- 按月聚合展示国内外量子会议
- 支持 URL 链接直达到会议官网
- 自动集成到周报会议日历板块

## 四、交互界面（Streamlit Dashboard）

Web 端局域网部署在 `0.0.0.0:8501`，包含 **7 个**核心功能页面：

1. **每日资讯** — 按日期浏览/搜索国内量子行业新闻
2. **投融资看板** — 跨库统一投融资事件视图，支持排序和筛选
3. **竞争对手** — 4 家核心竞对全量档案展示
4. **周报生成** — 一键触发 Issue N 周报生成流水线
5. **会议信息** — 量子科技会议日历（211 场会议）
6. **报告提醒** — 重要第三方行业报告追踪
7. **知识图谱** — 13,034 节点 / 11,864 条边的实体关系可视化探索

## 五、技术栈

| 层 | 技术选型 |
|----|---------|
| **语言** | Python 3.14 |
| **Web 框架** | Streamlit |
| **数据库** | MySQL 8.4（主库）、SQLite（历史/机构/竞对/会议） |

| **抓取** | requests + BeautifulSoup + Playwright（JS 渲染页面） |
| **标签/分词** | jieba + 自定义量子行业词典 |
| **部署** | Windows Server + PowerShell 自动化脚本 + OneDrive 备份 |
| **版本控制** | Git（4 个子模块 + 1 个主仓库），GitHub 远程 |

## 七、后续规划方向

1. **竞对档案扩展**：继续覆盖 IonQ、Quantinuum（离子阱）、IBM Quantum（超导）、D-Wave（量子退火）等核心玩家
2. **投融资自动化增强**：提高金额/估值自动提取准确率，扩大搜索覆盖域名
3. **统一标签中间层落地**：从碎片化打标升级为 jieba + 词典的统一标签体系（已规划，待实施）
4. **知识图谱扩充**：从 JSON 静态图升级为图数据库（如 Neo4j），支持更复杂的多跳关系查询
5. **周报分发**：自动化邮件/企业微信推送
6. **API 化**：将核心能力封装为 REST API，供其他系统调用

## 八、运行保障

- **一键启动脚本**：`startup.ps1` 自动检查 MySQL 就绪 → 清理冲突进程 → 启动 Streamlit → 打开浏览器
- **Cookie 管理**：cookies.txt（优先）→ pickle 文件的优先级机制，支持周级别自动更新
- **Git 备份**：4 个子模块 + 主仓库双推，变更即提交
- **故障排查 SOP**：覆盖 Cookie 过期、MySQL 连接失败、Streamlit 缓存、看板数值异常等常见问题
- **定时任务**：知识图谱每日更新（`.claude/scheduled_tasks.json`）
